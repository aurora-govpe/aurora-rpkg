# dev/ — project memory

This directory is the durable memory of the aurora project. It is
**.Rbuildignored** (never ships in the built package). Read in this order:

1. `STATE.md` — where we are; the resume point.
2. `PLAN.md` — phased roadmap with acceptance criteria.
3. `ARCHITECTURE.md` — the pattern and the app contract.
4. `DECISIONS.md` — ADRs (the why behind the invariants).
5. `LESSONS.md` — hard-won gotchas; append as you learn.
6. `PLUMBER2-NOTES.md` — the plumber2 API surface we rely on.
7. `BACKLOG.md` — unscheduled ideas and open questions.

`CLAUDE.md` at the repo root is the agent's operating manual and points here.
